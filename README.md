# C# Week 2 — Text RPG

## 구현한 기능
- Player / Enemy 전투
- HP 및 공격 시스템
- 상속 적용 Character 안에 Player, Enemy

## 클래스 구조
- Character: name, hp, attack을 가진 부모 클래스
- Player: Character 상속 받은 자식 클래스, 생성자에서 플레이어의 초기 상태 설정
- Enemy: Character 상속 받은 자식 클래스, 생성자에서 에너미의 초기 상태 설정
- Program: 이름 입력, 메뉴 선택, 전투 진행, 승패 판정

## 배운 점 / 막힌 점
상속, 예외 처리에서 막혔다. 
상속 클래스, 예외 처리
